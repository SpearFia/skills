Open the output's `index.html`. Compare each current edit with the supplied pop
alternatives, then download all four choices as `audition-selections.json`.
Only after those choices are supplied, use the same command with
`--selections C:/Users/caesa/Downloads/audition-selections.json` to assemble a
separate native review and full 14,891-frame Star 4 proxy preview. Keep/flag choices
retain the original card; flags remain unresolved in the completion report.
This export grants no production or HQ approval.

The nine previous creator selections become four grouped moments: 7 ROUNDS,
FIGHT WON / STILL WANTED, ROAD / BUILDING / SWAMP, and STAR 4: COSTLY SURVIVAL.
The original labels remain immutable. New variants map main text, source/context
lines and OUR GUESS qualifiers explicitly. The three escape alternatives use the
existing progressive list, not a misleading two-statement comparison. Existing
word observations supply reveal anchors; unresolved or ambiguous phrases stop
preparation. Each clip includes three seconds of surrounding footage where possible.

The recipe, native snapshot and creator export are pinned to the reviewed v3
fingerprints. Editorial inputs, narration observations, proxy dependencies and
archived review files are checked before and after rendering. The two live Stage 6
stop/run controls are reported separately: their state changed since the old
trial, and this workflow neither restores nor edits them. Other changed inputs
stop preparation. Output stays outside projects, previous reviews and Git.

Only mapped card IDs 1430, 1432, 1435 and 1437 may be disabled in working copies.
Adjustment layer 1505 and all unrelated clips/effects remain native. Silent,
caption-free inserts are composited in a separate native timeline, retaining
original caption and audio tracks. Audition exports explicitly burn the existing
native caption track once; the archived export had left caption burning off.
Each context's original mixed audio is trimmed
and encoded once, then reused by stream copy in every variant. The full-section
preview reuses the archived preview's original AAC stream without encoding it again.

`audition-plan.json` freezes input, candidate, timing and renderer identities.
Verified artifacts and inserts are hash-cached. An unchanged rerun does no new
rendering or model work. Changed inputs/renderer require a fresh output; partial
or modified artifacts are preserved and rejected. Selection exports are bound to
the audition fingerprint, and changed selections create separate result folders.

Review picture, timing and caption placement on the real clips. Existing evidence
warnings remain visible; a preferred layout does not verify the underlying claim.
